# FakturierungPro (Node.js / Express)

Dieses Backend basiert auf **Node.js, Express und Sequelize**.

## 🚀 Schnellstart

### 1. Voraussetzungen
* **Node.js** (LTS v20+).
* Laufende Datenbank (SQLite).

### 2. Installation
```bash
npm install
```

### 3. Konfiguration (.env)
Prüfen Sie die Datei `.env`.
Für SQLite wird die Datei automatisch erstellt.

### 4. Starten
```bash
# Startet den Server (Node 20+ mit --watch Support)
npm run dev
```

Die API läuft unter **http://localhost:5000/api**.

## 🧩 Features
* **ORM:** Sequelize (Auto-Sync beim Start).
* **Uploads:** local.
* **Webhooks:** 0 konfiguriert.
* **SSO:** Keine.
